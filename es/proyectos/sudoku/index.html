Sudoku Aplicación Web

Una aplicación web de Sudoku sin anuncios con un motor de rompecabezas personalizado · Abril 2026

React TypeScript Vite Web Workers CSS Pixel Art

Construí una aplicación web completa de Sudoku desde cero como proyecto de portafolio, con generación de puzzles usando un sistema de calificación de dificultad estilo humano, un diseño de pixel art con tema sakura, y una experiencia de juego completa con temporizador, marcador y múltiples niveles de dificultad.

Pantalla de inicio con tema de pixel art sakura

Descripción General

01 — Stack Tecnológico

Construido con herramientas modernas

React para la interfaz, TypeScript para la seguridad de tipos, y Vite para builds de desarrollo rápidos. La generación de puzzles corre en un Web Worker para mantener la interfaz responsiva.

02 — Sistema de Dificultad

Calificación estilo humano

Desarrollé un calificador de dificultad de siete técnicas que evalúa los puzzles basándose en las estrategias de resolución requeridas, no solo en el número de celdas eliminadas, imitando cómo un jugador humano evaluaría la dificultad.

03 — Funcionalidades

Experiencia de juego completa

Incluye temporizador de pausa/reanudación, marcador local para registrar mejores tiempos, múltiples niveles de dificultad y validación de entrada con resaltado de errores.

04 — Diseño

Tema de pixel art sakura

Estética de pixel art personalizada inspirada en los motivos de flor de cerezo japonesa. Diseñado para sentirse como un juego retro mientras mantiene una interfaz limpia y moderna.

Demo

Características Principales

  • Generación de puzzles con Web Workers para rendimiento de interfaz sin bloqueos
  • Calificador de dificultad estilo humano de siete técnicas para clasificación precisa de puzzles
  • Temporizador de pausa y reanudación con preservación del estado del juego
  • Marcador local que registra los mejores tiempos de completación por dificultad
  • Tema de pixel art sakura personalizado con diseño visual cohesivo
  • Diseño responsivo para jugar en escritorio y móvil
  • Validación de entrada y resaltado de errores en tiempo real

Aspectos Técnicos Destacados

El sistema de calificación de dificultad usa siete técnicas de resolución distintas — desde singles desnudos hasta patrones de ala en X — para clasificar cada puzzle. En lugar de simplemente contar celdas vacías, el calificador analiza qué estrategias necesitaría un solucionador humano, produciendo niveles de dificultad más precisos y satisfactorios.

La generación de puzzles corre completamente en un hilo de Web Worker, evitando que la interfaz principal se congele durante el proceso computacionalmente intensivo de generar y validar nuevos puzzles.
